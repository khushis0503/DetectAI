How it works

  1. 1

    Clean

    Unicode, links, HTML and formatting are normalised — the same cleaning used on the 8,895 training texts (essays, stories, news and Q&A answers).

  2. 2

    Tokenize

    The text is split into tokens. BERT uses WordPiece sub-words (e.g. unbelievably → un · ##bel · ##ie · ##va · ##bly); the baseline uses words, lemmas and TF-IDF weights.

  3. 3

    Classify

    A Transformer (BERT) reads each word in context with self-attention, or the baseline Logistic Regression + SVM scores word and character patterns. Output: the probability the text is AI-written.

  4. 4

    Decide & explain

    Thresholds set on validation data allow at most 5% of human texts to be labelled “Likely AI”. Word colours show which words pushed the decision.
